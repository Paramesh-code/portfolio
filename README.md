# Parameshwaran R — Portfolio

Animated personal portfolio for Parameshwaran R, .NET Backend Developer (real-time collaboration & distributed systems).

Single self-contained `index.html` — no build step.

## Run locally

```bash
python3 -m http.server 8080
# open http://localhost:8080
```

## Deploy

Works as-is on GitHub Pages, Netlify or Vercel (serve the repo root).
